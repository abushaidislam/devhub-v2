# Roadmap

This roadmap is ordered. Do not start a later phase merely because it is more visually impressive.

## Phase 0 — Foundation and truth

- [x] Typed tool registry
- [x] 12 independent local-first engines
- [x] Shared tool runtime
- [x] All Tools and Favorites workspaces
- [x] Command palette
- [x] Responsive Vercel-inspired shell
- [x] Agent context and documentation system
- [x] Add automated engine/component/E2E test foundations
- [x] Add continuous integration when repository permissions allow
- [x] Publish privacy, security, AI data, docs, accessibility, and accurate changelog routes

## Phase 1 — Habit and retention

- [x] Replace fake Recent behavior with real local history
- [x] Add privacy settings for history retention
- [x] Add favorites/workspace import and export
- [x] Add smart deterministic input detection
- [x] Add recommended next actions
- [x] Add PWA install and validated offline behavior
- [x] Instrument privacy-safe activation and retention events

## Phase 2 — Workflow differentiation

- [x] Introduce typed engine registry and value types
- [x] Add workflow schema and versioning
- [x] Add compatibility validator
- [x] Add sequential local runner
- [x] Add built-in recipes
- [x] Add saved recipe workspace
- [x] Add one-click re-run
- [x] Add safe share/export

## Phase 3 — AI assistance

- [x] Add natural-language workflow planning
- [x] Use BYOK provider configuration
- [x] Add per-action data disclosure and consent
- [x] Add safe error explanation
- [x] Evaluate local-model support (OpenAI-compatible local endpoints such as Ollama)

## Phase 4 — Distribution

- [ ] Validate repeat usage before integrations
- [ ] Browser extension for explicit selected-text actions
- [ ] VS Code extension using the shared contract
- [ ] CLI using the shared contract

## Non-goals until evidence changes

- Large random catalogue expansion
- Hosted anonymous AI at uncontrolled cost
- Enterprise administration
- Plugin marketplace
- Native desktop application
- Account system before local workflows retain users
