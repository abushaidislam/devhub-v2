# Product strategy

## Positioning

DevHub is a **free, local-first developer workflow workspace** for recurring API-debugging and data-transformation tasks.

Working promise:

> Detect, transform, and automate developer data without sending it away.

## Strategic wedge

Do not compete on total tool count. Focus first on web/API developers who repeatedly work with JSON, JWT, Base64, URLs, hashes, regex, SQL, cron, headers, logs, and schemas.

## Differentiation

1. Smart deterministic input detection.
2. Multi-step local tool chaining.
3. Saved, reusable workflow recipes.
4. Real recent/history with privacy controls.
5. Optional AI planning that composes deterministic tools.
6. Browser/PWA/IDE access after web retention is proven.
7. A small set of specialist-depth flagship workbenches.

## Retention loop

```text
Single-task visitor
  → successful local result
  → detected related action
  → uses multiple tools
  → saves a recipe
  → re-runs it later
  → installs PWA/extension
```

The north-star metric is **weekly users who successfully run a saved workflow**.

Supporting metrics:

- First-session completion
- First session with 2+ tools
- Favorite/recipe save rate
- Recipe re-run rate
- Command palette usage
- 7-day and 30-day activated retention
- Direct/bookmark traffic

Analytics must not capture raw tool input or output.

## AI role

Good uses:

- Natural-language workflow planning
- Suggesting compatible deterministic steps
- Explaining safe tool errors
- Generating editable recipes
- Optional BYOK assistance with explicit consent

Bad uses:

- Thin pages duplicating generic chatbot prompts
- Sending full inputs without confirmation
- Claiming local processing for hosted models
- Paying indefinitely for anonymous hosted AI traffic

## Free-product policy

- Core deterministic tools remain free.
- Local favorites, recipes, import/export, and PWA remain free.
- AI must use BYOK, local models, or explicitly controlled resources.
- Avoid ads that undermine privacy and premium presentation.

## Non-goals now

- Maximizing tool count
- Accounts before local retention works
- Enterprise controls before user demand exists
- A plugin marketplace before the engine contract stabilizes
- A desktop app before PWA/browser usage validates the habit

## Immediate product sequence

1. Trust and privacy surfaces.
2. Real Recent/history.
3. Smart input detection.
4. Typed engine registry.
5. Workflow runner and validation.
6. Saved local recipes.
7. AI workflow planner with BYOK.
8. PWA/browser/IDE integrations after retention evidence.
